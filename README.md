# eDAS数据处理软件（eDASpy ）

`eDASpy` 用于 eDAS 分布式光纤传感数据的浏览、滤波、去噪、时域/频域/时频分析、事件到时标注、车辆轨迹标记，以及当前视图数据导出。支持 `.bin`、`.bz`、`.bzs` 和本软件导出的 eDAS `.npz`。

本文按 **2026-10-16 当前源码界面及校验逻辑**整理。项目目录和旧参数存储名称保留 `eDASread`，界面名称为 `eDASpy`。表中默认值指首次使用、没有历史设置时的初始值；再次启动优先恢复上次保存的参数。

## 1. 共同约定与页面关系

### 1.1 通道号、位置点和数组列

软件中的“通道”“位置点”“道号”表示同一个空间维度。普通原始文件的编号从 **0** 开始：有 N 个位置点时，合法编号为 `0～N−1`，例如 100 点的文件编号为 `0～99`。

通道范围**包含两端**：`0~99` 共 100 点，`20~20` 只取通道 20。文件名中的 `0100pt` 表示位置点数量，不表示最后一个编号。

裁剪或空间降采样后的 NPZ 保留原始通道身份。例如 `channel_start=20`、`channel_step=2`、三列数据对应的通道号为 **20、22、24**。在所有页面输入通道号时，应使用这些实际存在的号码；输入已经移除的 21 会报错。下表中的“有效通道”均指当前文件实际保存的通道集合。

通道号与物理距离的换算为：

```text
距离(m) = 首道位置(m) + 通道号 × 原始道间距(m)
```

首道位置 0 m、道间距 5 m 时，通道 0/1/2 对应 0/5/10 m；NPZ 保留通道 20/22/24 时，对应 100/110/120 m。

从旧版升级时，已保存的旧通道参数会一次性减 1，使其仍指向原来的数据列；以后启动不重复转换。

### 1.2 采样率、时间和单位

本文记采样率为 `fs`，采样间隔为 `1/fs` 秒，奈奎斯特频率为 `fN=fs/2`。

- 波形和相位颜色图使用弧度 `rad`。原始整数转换关系为 `rad = int32 × π / 32767`，程序不会自动换算为应变或位移。
- 有采集时间时，时间轴按文件首样本的采集时间显示；没有时间信息时显示相对时间。
- Tab1 到时内部及 NPZ 中的 `time_s` 是相对当前文件首个保存样本的秒数，首样本为 0 秒。
- N 帧数据的标称时长为 `N/fs` 秒；最后一个真实样本的时刻为 `(N−1)/fs`。到时不能超过最后一个样本。
- 多选文件按采集时间/文件名排序后沿时间轴直接接续；软件不会根据时间戳自动补缺、去重或消除重叠。应选择实际连续的数据文件。

### 1.3 参数输入规则

| 输入类型 | 规则与示例 |
| --- | --- |
| 通道范围 | Tab1 用 `a~b`，如 `0~99`；Tab3 支持 `a-b`、`a:b`、`a~b`；均含终点。 |
| 通道列表 | Tab2 用 `0,4,9`；也接受空格、中文逗号、顿号、英文分号分隔。 |
| 显示数值范围 | 一般为下限小于上限；需要一对数值的参数须两端都填，或在明确支持自动值的地方两端都设自动。 |
| 自动值 | 只有明确标为支持的参数才使用留空或 `auto`；合并范围常写 `auto~auto`。不要把 `auto` 作为所有输入框通用值。 |
| 频率简写 | 仅 Tab1/Tab4 的滤波输入支持 `k` 后缀，例如 `5k~20k` 表示 5000～20000 Hz；其他频率框填写普通 Hz 数字。 |
| 数值 | 使用有限实数；道号、窗长采样点数、NFFT、抽取步长等要求整数的参数不填小数。 |

部分几何输入框有固定输入上限；其他参数的业务范围依赖当前文件，如通道数、采样率和帧数。下文分别说明输入范围和数据限制，不把“显示范围”误作“滤波频段”。

### 1.4 各页使用哪一份数据

| 页面/功能 | 使用的数据 | 是否改变 Tab1 的数据 |
| --- | --- | --- |
| Tab1 基础滤波、去噪 | 当前选中文件拼接后的矩阵 | 是，成为其余页面的分析输入。 |
| Tab1 颜色图/Wiggle、增益、填充、点段 | 当前处理后矩阵的显示切片 | 只改变显示，不改样本值。 |
| Tab2 时域/PSD | Tab1 当前处理后的完整矩阵中指定通道 | 否。 |
| Tab3 f-k 谱 | Tab1 当前处理后的完整矩阵中指定连续点段 | 否，只计算/显示谱。 |
| Tab4 时域/时频 | Tab1 当前处理后数据，另可对单通道附加滤波 | 否，附加滤波仅用于 Tab4。 |
| Tab5 相位/能量图 | Tab1 当前拼接、处理后数据的指定通道段 | 否，能量转换只用于 Tab5。 |
| 未勾“处理后”的 BIN/TXT 导出 | 源文件原始 int32 切片 | 不使用滤波/去噪后的显示矩阵。 |
| NPZ 导出 | 源文件原始 int32 + 头信息 + 当前到时 | 始终保存未滤波整数。 |

**Tab1 点段只限制显示，不会把已载入矩阵永久裁掉。** Tab2～Tab5 仍可选择当前文件中其他实际存在的通道。去噪处理作用于当前载入矩阵；最后保存哪些时间和通道，由 Tab1 当前视图与导出步长决定。

## 设置与文字大小

点击标题栏右上角“设置”，调整“界面文字大小”。首次启动默认为 **18px**，允许 **12～28px** 的整数；已有设置时恢复上次保存值。

| 设置/按钮 | 作用 |
| --- | --- |
| 界面文字大小 | 同步调整各页参数、按钮、文件列表、页签、图表坐标及色条文字；标题保持更大字号。 |
| 应用 | 立即生效并保存，窗口继续打开。 |
| 确定 | 应用、保存并关闭设置窗口。 |
| 取消 | 关闭窗口，不应用尚未提交的修改；已经点击“应用”的设置仍保留。 |
| 恢复默认 | 将窗口内字号改回 18px，再点击“应用”或“确定”生效。 |

参数输入框会随字号加宽；窗口较窄或字号较大时，参数区显示横向滚动条，可滚动查看右侧控件，保持原有紧凑行数。修改字号不会改变数据、到时或轨迹，无需重新加载文件。

## 2. 左侧文件列表与批量压缩

### 2.1 控件与用法

| 控件 | 可设置值/范围 | 使用方法 |
| --- | --- | --- |
| 目录输入框 / 目录 | 存在的数据目录 | 点击“目录”选择文件夹；也可直接输入路径并按 Enter，或等待目录更新。 |
| Sort：Name | 按文件名升序 | 适合带序号或时间戳的数据集。 |
| Sort：Modified: Newest / Oldest | 修改时间从新到旧/从旧到新 | 只改变列表顺序，不改变拼接所依据的文件元信息排序规则。 |
| 文件列表 | 单选或 Ctrl/Shift 多选 | 单击读取一个文件；Ctrl 多选离散项，Shift 选择连续项。整组读取完成后再处理或导出。 |
| 上一页 / 下一页 | 每页 100 个文件 | 切换文件列表页。 |
| 跳页框 / 跳转 | `1～总页数`，或 `home`、`end` | 输入页号跳转，home 为首页，end 为末页。**页码从 1 开始，与通道号不同。** |
| 批量压缩 | 当前目录内全部 `.bin` | 将当前目录的原始 BIN 批量压缩为 BZ；已有同名 BZ 默认跳过。 |

批量压缩输出到 Tab1 导出目录；未设置导出目录时输出到当前数据目录。点击后会显示数量和输出目录确认框，确认后开始后台压缩。只处理本目录内的 BIN，不递归扫描子目录，也不处理 NPZ/TXT。BZ/BZS 需要可用的 zstd 支持。

### 2.2 文件格式与多文件要求

| 格式 | 读取要求 |
| --- | --- |
| `.bin` | 原始 int32，frame-major，形状为帧×点。文件名需包含采样率和点数，例如 `eDAS-2000Hz-0130pt-20261016T120000.000.bin`。 |
| `.bz` / `.bzs` | 从压缩包头读取元信息；文件名如包含采样率/点数，会核对其与包头一致。 |
| `.npz` | 必须符合本软件的 eDAS NPZ 协议，`header.data_type` 精确为 `eDAS`；不要求固定文件名。普通 NumPy NPZ 不作为 eDAS 文件读取。 |
| `.txt` | 本软件可导出 TXT，但当前文件列表不支持将 TXT 重新载入。 |

多文件拼接要求：**通道数量、实际通道起点、通道间隔和采样率一致**。空文件、没有完整数据帧、文件大小与 BIN 点数不匹配等情况会拒绝读取。拼接时长等于各文件帧数之和除以采样率。

首次快速操作：选目录 → 选文件 → 等待状态栏加载完成 → 在 Tab1 设置有效点段和滤波 → 点击“应用”。默认滤波 `10~` 只适用于 `fs>20 Hz` 的文件；低采样率文件应清空滤波或改用满足奈奎斯特约束的截止频率。

### 2.3 文件列表刷新与大量文件目录

- 点击左侧 **“刷新”**，或在主窗口按 **F5**，重新读取当前目录的新增/删除文件。目录不变时尽量保留当前页和仍存在的所选文件；刷新本身不重复加载已选波形。
- 文件列表上方显示“正在扫描文件…”或文件总数。目录扫描与名称/修改时间排序均在后台完成，列表每页只创建最多 100 个条目。扫描不读取所有数据文件的头和样本；真正选中文件后才读取该文件的数据。
- 正在扫描时仍可操作界面。再次刷新、切换目录或更改排序，会取消旧扫描并优先处理最新请求，旧结果不会覆盖新目录；按文件名排序不读取逐文件修改时间。
- 目录不存在、无权限或读取失败时，列表显示失败提示；修正路径后重新刷新。目录中途删除的文件会跳过，扫描不递归子目录。
- 批量压缩前等待文件列表刷新完成；批量压缩的确认计数采用当前目录列表，不在界面线程重新扫描上万个文件。
- 网络盘、移动磁盘或实时采集目录的实际扫描耗时取决于存储速度；后台运行可保持界面可操作，但无法让底层磁盘/网络访问立即返回。文件变更按扫描时刻形成快照，需要更新时再次刷新。

## 3. Tab1 数据处理

Tab1 采用三行常驻区域：显示参数、操作/处理入口、导出设置。选择多道波形后再显示一行波形参数。“坐标设置”和“去噪处理”打开弹出面板，不长期占用额外行。

### 3.1 常用显示与基础滤波参数

| 界面参数 | 初始值 | 可设置范围/格式 | 含义与生效方式 |
| --- | --- | --- | --- |
| 点段（原 Point Range） | `0~99` | `a~b`，整数，a≤b，两端必须为有效通道 | 控制下方颜色图/Wiggle 的通道范围。无手动覆盖时自动显示前 100 点，不足 100 点则到文件末道。改后点击“应用”。 |
| 振幅（原 Color Range） | `-0.4~0.4` | 有限浮点 `a~b`，a<b，单位 rad | 颜色图的色阶下限/上限；例如 `-0.1~0.1` 强调小幅波动。使用完整的两端数值，改后点击“应用”。不改变实际数据，也不等于 Wiggle 的限幅。 |
| 色表 | `seismic` | `seismic`、`jet`、`hsv` | 颜色图映射，切换即时生效。seismic 便于比较正负相位。 |
| 图型 | `时空颜色图` | `时空颜色图` / `多道波形(Wiggle)` | 下方图即时切换；切换后恢复该图完整时间/通道范围。保存过设置时启动可直接进入 Wiggle。 |
| 波形点 | `0` | 当前点段内一个实际存在的通道号 | 上方单道时域图和“播放”的目标通道；编辑完成或滚轮步进后更新。在带空间间隔的 NPZ 中按保存的通道步长移动。 |
| 单道时域 | 勾选 | 勾选/取消 | 控制上方单道波形是否显示；取消后下方图获得更多高度。 |
| 滤波(Hz) | `10~` | 见下表；频率必须满足 `0<f<fN` | 4 阶 Butterworth 零相位时间滤波，逐通道作用于载入矩阵。改后点击“应用”。 |

滤波输入举例：

| 输入 | 含义 | 合法条件 |
| --- | --- | --- |
| 留空 / `none` / `auto` | 不进行 Tab1 基础滤波 | 仍会将原始整数换算为 rad。 |
| `10~` | 10 Hz 高通 | `0<10<fs/2`。 |
| `~300` | 300 Hz 低通 | `0<300<fs/2`。 |
| `10~300` | 10～300 Hz 带通 | `0<10<300<fs/2`。 |
| `5k~20k` | 5000～20000 Hz 带通 | 需要 `fs>40000 Hz`；不是所有文件都能用。 |

截止频率不能等于奈奎斯特频率。短数据可能不足以完成前后向滤波，应使用更长数据段或不滤波。不要只输入单个 `10` 来代替高通，明确写成 `10~`。

### 3.2 操作按钮

| 按钮 | 功能 | 使用时机 |
| --- | --- | --- |
| 应用 | 按当前基础滤波设置重新加载所选单文件/整组文件并绘图 | 更改点段、振幅范围或基础滤波后。重新应用会回到该基础滤波结果，之前逐项叠加的去噪需重新执行。 |
| 重置 | 恢复 Tab1 主要显示、滤波、坐标和 Wiggle 默认值，并重新读取当前列表文件 | 需要重新开始配置时。多选拼接任务应在重置后重新确认整组选择并“应用”。 |
| 全视图 | 恢复当前显示点段的完整时间/通道窗口 | 取消局部缩放；不会重读数据或撤销去噪。 |
| 返回 | 回到上一个已记录的视图窗口 | 逐步返回缩放/平移前的视图。 |
| 缩小 2× | 将当前时间窗口横向扩大，最多到完整时长 | 查看更多前后事件，不改变数据。 |
| 播放 | 播放当前“波形点”的完整处理后波形 | 使用 Windows 声音播放；软件先去直流、按分位幅值缩放并限幅，必要时重采样到音频采样率。听到的是归一化音频，不代表原始振幅标定。 |
| 去噪处理 | 打开四项去噪和 FK 参数 | 见 3.4。 |
| 坐标设置 | 打开通道/距离与几何参数 | 见 3.3。 |
| 清除到时 | 删除当前文件组全部到时 | 只删除标记，不改变样本。 |

### 3.3 “坐标设置”弹出面板

| 参数 | 初始值 | 可设置范围 | 含义 |
| --- | --- | --- | --- |
| Y 轴 | `通道号` | `通道号` / `距离` | 用实际通道编号或物理距离作为纵轴标签；不改变通道选择和数据列。 |
| 单位 | `m` | `m` / `km` | 仅距离模式可用；显示单位转换，不改变原始米制参数。 |
| 道间距(m) | `5` | 输入框 `0.001～1000000`，最多 3 位小数，必须>0 | 原始相邻通道的物理间距。NPZ 保存间隔为 2 时，相邻保存列的距离差为此值×2。 |
| 首道位置(m) | `0` | 输入框 `−1000000～1000000`，最多 3 位小数 | **原始通道 0** 的位置，可为负；不是裁剪后第一列的位置。 |

改变这些参数会更新距离轴。换算始终是 `首道位置 + 实际通道号×道间距`，例如 NPZ 从通道 20 起，首道位置仍为 0、道间距为 5 时，第一列显示 100 m。

### 3.4 “去噪处理”弹出面板

先执行基础滤波，再根据需要逐项点击去噪；每次结果成为下一步输入，顺序会影响结果。状态栏记录当前叠加的处理步骤。

| 功能/参数 | 初始值与范围 | 含义与操作 |
| --- | --- | --- |
| 去尖峰噪声 | 无可编辑算法阈值 | 根据局部中值检测异常尖峰并插值替换；点击后后台处理当前载入矩阵。 |
| 去共模噪声 | 无可编辑算法阈值 | 估计多个通道共有的波形成分并扣除；与 Tab5 能量图中的“去共模”是不同处理阶段。 |
| 去随机噪声 | 至少 8 帧且至少 8 通道 | Curvelet 系数阈值去噪，通常比前两项耗时；不要连续重复点击启动。 |
| FK滤波 | 至少 2 帧、2 通道 | 压制较低视速度成分、保留较高视速度能量。先设 DX、VMin/VMax，再点击。 |
| DX(m) | `5`；输入框 `0.001～1000000`，最多 3 位小数，必须>0 | 原始相邻通道间距；NPZ 输入会乘保存的通道步长，得到实际计算间距。 |
| VMin | `800` m/s；输入框 `0.001～1000000`，最多 3 位小数 | FK 速度过渡区下界，必须>0，不能与 VMax 相等。 |
| VMax | `1200` m/s；同上 | FK 速度过渡区上界。建议始终 VMin<VMax；处理层会对输入两端排序。 |

视速度小于等于 VMin 的成分被压制，大于等于 VMax 的成分保留，中间余弦过渡。这里的 VMin/VMax 单位是 **m/s**；Tab3 的 V(dB) 是谱图色阶，含义不同。

去噪作用于当前载入矩阵，不仅是当前可视时间窗。需要只保存局部结果时，去噪完成后再缩放 Tab1 并导出。要撤掉已叠加的处理，重新“应用”基础滤波；重新加载通常也会刷新其他页所依据的数据，因此应重新点击相应页的绘制按钮。

### 3.5 多道波形（Wiggle）参数

切换“图型”为多道波形后出现。纵轴为实际通道号/距离，横轴为时间；每道的基线放在该通道纵坐标上。

| 参数 | 初始值 | 可设置范围 | 含义 |
| --- | --- | --- | --- |
| 缩放 | `全局最大值` | 七种模式，见下表 | 仅对显示振幅作归一化。 |
| 增益(dB) | `0` | 整数 `−60～60`；加减按钮每次 5 dB | 振幅乘以 `10^(dB/20)`；滑块与数字框同步。 |
| 负向翻转 | 不勾选 | 勾选/取消 | 反转所有显示波形极性。 |
| 限幅 | `0` | 建议有限非负数；`0` 表示不限制 | 对归一化和增益后的显示振幅削幅，不是原始 rad 限幅，也不改变导出值。 |
| 填充 | 勾选 | 勾选/取消 | 填充波形与基线之间的面积。 |
| 负向填充 | 不勾选 | 勾选/取消，依赖填充开启 | 不勾选只填正侧；勾选填充正负两侧。 |
| 间隔 | `地震道` | `地震道` / `像素点` | 选择按数据列步长或按屏幕像素间距选道。 |
| 步长 | `1` | 地震道：使用整数≥1；像素点：有限正数 | 地震道模式 1 绘制全部选中列，2 每两列绘制一列，无隐式 150 道上限。像素点模式按当前窗口高度估计抽稀，缩放后可变化。 |

| 缩放方式 | 归一化依据 |
| --- | --- |
| 全局最大值 | 当前点段所有通道的估计最大绝对振幅。 |
| 三道最大值 | 当前通道及相邻通道、最多三道的估计最大绝对振幅。 |
| 单道最大值 | 当前通道自身的估计最大绝对振幅。 |
| 全局均方根 | 当前点段全部通道的估计 RMS。 |
| 三道均方根 | 当前道及相邻通道的估计 RMS。 |
| 单道均方根 | 当前通道的估计 RMS。 |
| 全局平均值 | 当前点段数据的估计平均绝对振幅。 |

长数据的统计量可能用抽样估计，绘图也使用时间包络以减少显示负担；这不会降低内部原始数据或导出的分辨率。单道归一化便于比较波形形状；全局归一化便于比较相对强弱。波形参数调整直接刷新，通常无需重新“应用”。

**间隔为 1 的说明**：旧版额外限制最多 150 条，750 道会再次按 5 抽稀；当前限制已经删除。全道绘制较重时可手动增加步长，软件不会暗中将 1 改成 5。

### 3.6 事件到时标注

1. 选择单文件或连续文件组，等待加载完成。
2. 在 Tab1 选多道波形，设好点段、显示步长和增益。
3. 按 Ctrl，用左键在目标通道的目标时间点击，出现红色短竖线。
4. 保持 Ctrl+左键，从多道划过；程序按实际拖动方向为经过的通道标注，鼠标事件稀疏时插值补齐中间通道。短暂离开绘图区后返回可继续。
5. 鼠标悬停已有标记通道，按 Ctrl+←/→，每次向前/后微调一个当前采样间隔。
6. 标错时在绘图区按 Esc 删除最近修改的一个通道当前标记；长按连续删除；“清除到时”一次清空当前组。
7. 选择 NPZ 导出，以在以后恢复标记。

每通道一个到时，重复点击或微调会更新该通道并使其成为“最近修改”。Esc 删除当前标记，不恢复该通道更早的旧时间。正在输入框编辑、打开菜单或对话框时，Esc 优先用于原控件。

增益、滤波、点段和模式切换不清除当前文件组的到时；颜色图隐藏红线，切回 Wiggle 恢复。各文件组在当前会话中分开保留，退出软件前需用 NPZ 保存需要长期保留的标记。

## 4. Tab2 多通道时域与 PSD

上图显示多个通道的时域波形，下图显示相同通道的 Welch 功率谱密度。输入来自 Tab1 当前处理后矩阵，不会重新执行基础滤波。

**按通道清除到时：**在 Tab1 多道波形图中，同时按住 **Ctrl+Shift**，鼠标左键短按清除所在通道的到时；左键长按并拖动，连续清除经过的通道。只按通道定位，无需点击红线的时间位置。快速拖动也会清除跨过的中间通道；无标记的通道直接略过。此操作不修改波形样本，颜色图下不生效。清除后如需保留结果，应重新导出 NPZ；Esc 继续表示删除最近标记，不会恢复已清除的到时。

### 4.1 参数

| 参数 | 初始值 | 可设置范围 | 含义 |
| --- | --- | --- | --- |
| 通道 | `4,9,14` | 至少一个有效通道号的列表，如 `0,4,9` | 每个通道画一条时域线和一条同色 PSD。小于 15 通道的文件需修改初始列表。 |
| PSD窗长 | `auto` | 整数≥8，或留空/auto | Welch 每段的采样点数，不是秒数。实际不超过当前 PSD 数据段长度；自动为 `min(max(256,int(fs)),4096,数据段点数)`。 |
| 重叠(%) | `50` | `0≤值<100` | 相邻 Welch 分段重叠比例，0 为不重叠；实际重叠点数限制小于窗长。 |
| FMin / FMax | 空，自动 | 两端均留空/auto，或有限数 `0≤FMin<FMax` | PSD 横轴显示范围，单位 Hz；建议 `0<FMin<FMax≤fN`。不改变滤波或 PSD 计算数据。 |
| PSD Min / PSD Max | 空，自动 | 两端均留空/auto，或任意有限 dB 数且 Min<Max | PSD 纵轴显示范围，允许负值。 |
| 绘制 | 按钮 | 数据段至少 8 个采样点 | 应用本页参数并绘制/重绘。 |

PSD 横轴是对数频率轴，0 Hz 不能以有限对数坐标显示；输入 0 会受内部显示下限处理。自动显示且 `fN>10 Hz` 时，默认横轴从 10 Hz 到 fN。需要看 10 Hz 以下频段时，显式填写如 `FMin=0.1`、`FMax=10`。

窗长越大，频率网格通常越细，可平均的段数相应减少；重叠增加可利用更多分段，但也增加计算量。PSD 值显示为 `10*log10(功率谱密度+小量)`。

### 4.2 使用与局部 PSD

1. 在 Tab1 完成基础滤波/去噪。
2. 在 Tab2 输入实际存在的通道列表，设置窗长和重叠。
3. 点击“绘制”，按图例颜色对应查看。
4. **在上方时域图按 Ctrl+左键拖动时间段**，下方 PSD 会在松开后按该段重新计算。所选段至少需要 8 个采样点。
5. 如需恢复完整数据的 PSD，再次点击“绘制”。

时域线会扣除各自中位数并施加不同纵向偏移，便于分辨多条波形；这些偏移不是通道之间的真实直流差。普通拖动可框选放大，滚轮缩放；先点击某一子图，再用左右键平移该子图。PSD 子图左右键沿对数频率方向移动。

## 5. Tab3 f-k 谱

f-k 谱用于观察频率 f 与空间波数 k 的能量分布、传播方向和视速度。它对 Tab1 当前处理后的连续通道段计算频率—波数谱，不执行 Tab1 的“FK滤波”。

### 5.1 参数

| 参数 | 初始值 | 可设置范围 | 含义 |
| --- | --- | --- | --- |
| 通道范围 | `4-99` | 有效通道范围，支持 `a-b` / `a:b` / `a~b`，含终点 | 至少两列数据，且至少两个时间采样点。小文件需改成实际范围。 |
| 间距(m) | `5` | 有限正数，无额外固定业务上限 | 原始相邻通道间距；NPZ 自动乘保存的通道步长，得到相邻计算列的有效间距。 |
| 空间taper | `0` | `0～1`；留空/auto 用默认值 | 空间方向 Tukey 边缘渐变比例；0 不加空间渐变，增大可减轻边界影响。 |
| 时间taper | `0.05` | `0～1`；留空/auto 用默认值 | 时间方向边缘渐变比例。 |
| NFFT-K | `auto` | 留空/auto，或整数≥实际所选通道数且≥2 | 空间 FFT 长度，自动取不小于通道数的 2 的幂。 |
| NFFT-T | `auto` | 留空/auto，或整数≥参与计算的时间点数且≥2 | 时间 FFT 长度，自动取不小于时间点数的 2 的幂。 |
| 扣除背景 | 勾选 | 勾选/取消 | 从谱图中扣除每个频率的空间波数方向中位背景，突出相对能量。 |
| F(a~b) | `auto~auto` | 自动，或 `0≤a<b`，单位 Hz | 频率显示范围；数据有效正频率范围为 0～fN。扩展显示范围不会生成额外频率信息。 |
| K(a~b) | `auto~auto` | 自动，或有限实数 `a<b`，单位 cycles/m，可含负值 | 波数显示范围；正负波数对应不同传播方向。 |
| V(dB) | `-20~0` | 两个有限数 `a<b`，允许负值 | 谱图相对幅值 dB 色阶；此处 V 是颜色范围，不是速度。 |
| 绘制 f-k 谱 | 按钮 | 上述参数有效 | 后台计算并显示。 |

有效空间采样间距为 dx 时，空间奈奎斯特波数约为 `1/(2*dx)` cycles/m；只扩大 K 显示范围不会增加空间分辨率。视速度可按 `abs(f/k)` 理解，k=0 附近需单独考虑。增大 NFFT 会细化计算网格并增加内存/耗时，不增加原始观测信息。

### 5.2 使用步骤

1. 完成 Tab1 的数据处理，再到 Tab3 输入连续通道范围。
2. 确认原始道间距，初次可保持默认 taper 和自动 NFFT。
3. 点击“绘制 f-k 谱”，观察谱图正负 k 方向和不同 f 分布。
4. 根据已有谱图范围填写 F、K、V，再点击绘制；也可滚轮缩放、拖动框选查看局部。
5. 若要按视速度实际改变数据，回到 Tab1 的“去噪处理→FK滤波”设置 DX、VMin/VMax 并执行，再回本页重绘比较。

Tab3 当前计算使用所选通道段的完整载入时间序列，不会自动只取 Tab1 缩放后可见的时间段。

### 6.1 参数

| 参数 | 初始值 | 可设置范围 | 含义 |
| --- | --- | --- | --- |
| 通道 | `0` | 一个实际存在的通道号 | 选择要分析的单道。 |

3. 点击“绘制时频图”，查看上方波形与下方事件频率分布。

## 7. Tab5 车辆轨迹标记

Tab5 用同一份拼接数据绘制相位图或交通能量图，并通过折线记录车辆在时间—通道图上的轨迹。它与 Tab1 的逐道“事件到时”是两个独立标注功能。

### 7.1 图像与能量参数

| 参数 | 初始值 | 可设置范围 | 含义 |
| --- | --- | --- | --- |
| 图像类型 | `能量图` | `能量图` / `相位图` | 能量图执行本页预处理；相位图直接显示 Tab1 当前处理后的相位。 |
| 通道起点 / 通道终点 | `199` / `819` | 两端为有效通道，范围含终点；反向输入会交换 | 生成图像的通道段。少于 820 点的文件必须改默认范围，例如 `0` 和 `99`。 |
| 低频(Hz) | `0.05` | 能量模式要求 `0<低频<高频<fs/2` | 能量生成前带通处理的低截止频率。 |
| 高频(Hz) | `10` | 同上 | 能量生成前带通处理的高截止频率。 |
| 降采样 | `10` | 整数≥1，且不大于可用帧数 | 能量包络按连续时间块平均，等效采样率 `fs/倍数`；尾部不足一个块的样本舍去。 |
| 通道均衡 | `p999` | `p999` / `mad` / `none` | 减少通道强弱差异。p999 按各通道 99.9 分位估计尺度；mad 在当前实现中按各通道中位数估计尺度并设防除零下限；none 不均衡。 |
| 去共模 | 勾选 | 勾选/取消，仅能量模式 | 对本页滤波数据逐帧扣除所有所选通道的均值。 |
| 生成能量图 / 绘制相位图 | 随模式显示 | 当前数据组已加载完成 | 重新生成所选类型的图。 |

能量模式流程：本页带通 → 可选去共模 → Hilbert 包络 → 时间块平均 → 逐通道时间中位数基线扣除 → 截断非负 → 可选通道均衡。输入至少 16 帧，实际还须满足零相位滤波长度要求。显示的“能量”是该处理链的相对包络强度，不是额外标定的绝对物理能量。

切到相位图后，低频、高频、降采样、去共模和均衡输入会禁用；相位图使用当前载入的时间采样率。这些参数与 Tab1 导出的“时步”不同：**Tab5 为包络块平均，导出时步为直接抽样**。

### 7.2 色条与显示

| 参数 | 初始值 | 可设置范围 | 含义 |
| --- | --- | --- | --- |
| Colormap | `inferno` | `inferno`、`viridis`、`plasma`、`magma`、`jet`、`turbo`、`seismic`、`hsv` | 相位/能量图色表，切换可直接更新。 |
| VMin / VMax | 空，自动 | 颜色自动时忽略；手动时两个有限数且 VMin<VMax | 颜色范围，相位模式单位 rad，能量模式为处理后相对强度。 |
| 颜色自动 | 勾选 | 勾选/取消 | 相位按绝对值 99 分位生成对称范围；能量按 0～99.5 分位估计范围。 |
| 应用颜色条 | 按钮 | 已有图像 | 应用当前色表与自动/手动色阶，无需重新生成图像。 |

### 7.3 标注、编辑和保存轨迹

1. 左侧选择一个或多个连续文件，等待整组加载完成。
2. 进入 Tab5，选择能量图或相位图，设置合法通道起止；能量模式再设置滤波与降采样。
3. 点击生成/绘制按钮。**重新生成会清除当前轨迹**，已有标注应先导出。
4. 依次左键点选一条轨迹的起点、可选中间点、终点；至少两个点后点击“完成当前轨迹”。
5. 可以继续添加其他轨迹。在右侧列表勾选/取消可显示或隐藏某条轨迹，隐藏不删除数据。
6. 使用下表编辑，完成后导出 JSON 或 CSV。

| 操作/按钮 | 功能与范围 |
| --- | --- |
| 完成当前轨迹 | 将当前至少两个顶点组成的直线/折线加入已完成列表。 |
| 撤销当前点 / Ctrl+Z | 删除尚未完成轨迹的最后一个点；不删除已完成轨迹。 |
| 删除所选轨迹 | 删除右侧列表当前选中的完整轨迹。 |
| 清空全部轨迹 | 清除已完成轨迹和未完成顶点。 |
| 导出标注 JSON/CSV | 保存已完成轨迹；仍在编辑的顶点应先点击“完成当前轨迹”。 |
| 载入标注 JSON | 读取已有 JSON 并替换当前轨迹列表；可继续编辑。CSV 当前仅导出，不支持在此载入。 |

JSON 保存源文件列表、图像模式、等效采样率、通道范围和各轨迹点；每点为“相对首帧秒数 + 实际通道坐标”。沿图点击的通道坐标可为小数，表示几何位置，不是 Tab1 的逐道离散到时。轨迹 ID 从 1 开始、顶点序号从 0 开始，它们均不是通道编号。

新 JSON 使用 `edasread-traffic-trajectories-v2`、`0_based_channel`；载入旧 v1 / `1_based_channel` 时通道坐标减 1。历史 CSV 无坐标版本字段，使用旧 CSV 时需自行进行旧编号换算。NPZ 中保存的是 **Tab1 到时**，不自动包含 Tab5 轨迹；Tab5 轨迹应单独导出 JSON/CSV。

Tab5 普通左键用于添加顶点；Ctrl+左键拖动框选放大，右键拖动平移，滚轮缩放。不要将本页的 Ctrl 操作与 Tab1 到时标注混用。

## 8. 数据导出、降采样与 NPZ 读取

### 8.1 Tab1 导出行参数

| 参数 | 初始值 | 可设置范围 | 含义与使用 |
| --- | --- | --- | --- |
| Export folder / 路径 | 空；有默认数据目录或历史设置时可预填 | 可写目录 | 输入或用“目录”选择。未存在的目标目录会尝试创建。 |
| 目录 | 按钮 | 文件夹 | 选择导出位置。 |
| 格式 | `BIN` | `BIN` / `TXT` / `NPZ` | 替代旧版 Save as txt 复选框，旧设置可恢复。 |
| 时步 | `1` | 输入框整数 `1～1000000` | 在当前时间裁剪范围内每隔该步长保留一帧；导出采样率 `fs/时步`。 |
| 道步 | `1` | 输入框整数 `1～1000000` | 在当前通道裁剪范围内每隔该步长保留一列；不是直接减小通道编号。 |
| 处理后 | 不勾选 | 勾选/取消；NPZ 模式禁用 | BIN/TXT 是否使用当前已滤波/去噪的矩阵。NPZ 始终使用原始整数，即使之前勾选过此项。 |
| 导出视图 | 按钮 | 有数据且选中组已加载完成 | 固定点击时的范围、源文件、格式、步长和到时快照，在后台执行。 |

显示用 Wiggle 步长不等于导出道步。即使显示每 5 道一条，只要导出道步仍为 1，当前可视通道范围内的数据列仍全部保存。反之，需要导出空间降采样结果时要修改“道步”。

### 8.2 导出范围与格式差异

先在 **Tab1 下方图**缩放至需要的时间/通道窗口，再导出。坐标显示为距离时，软件仍会映射回相应通道列。只缩放其他 Tab 不会改变 Tab1 导出范围。

时间按采样网格截取，起始帧取可视起点×fs 的向下取整，结束帧取可视终点×fs 的向上取整，并限制在文件中；数组结束帧不包含在内。通道范围按可见像素单元映射到实际列，再进行空间抽取。最终以导出文件的实际帧数、列数和头信息为准。

| 格式 | 数据内容 | 保存元信息/到时 | 重新读取 |
| --- | --- | --- | --- |
| BIN | frame-major int32；可原始，也可由处理后 rad 换算 | 文件名记录采样率、点数和首样本时间；不携带原通道身份或到时头 | 支持；作为普通从 0 编号的原始矩阵读取。 |
| TXT | 帧×通道的 rad 浮点文本，每列一个保存通道 | 不携带 NPZ 头或到时 | 当前 GUI 不支持重读 TXT，可用其他数值工具读取。 |
| NPZ | **未滤波 int32** + JSON 头 | 保存原通道起点/间隔、采样率、时间、到时等 | 支持，恢复实际通道号与红线。 |

原始导出从源 BIN/BZ/NPZ 读取，避免原始 int32 经 float32 往返丢失整数精度。多文件时间抽取跨文件边界连续，不在每个文件重新起算。导出路径不能与本次源文件相同。

### 8.3 降采样示例

输入采样率 2000 Hz，当前视图包含原始通道 20～30，设置时步 2、道步 2：

- 每两帧保留一帧，输出采样率 1000 Hz。
- 每两列保留一列，输出原通道为 20、22、24、26、28、30。
- NPZ 中 `channel_start=20`、`channel_step=2`、`channel_count=6`。
- 如果输入 NPZ 的通道间隔本身已为 2，再设道步 2，输出的通道间隔会累计为 4。

两种导出降采样均为**直接抽取，不平均、不进行抗混叠滤波**，以保持 NPZ 原始整数值。分析带宽应与新的采样率匹配；希望保留预先滤波后的降采样数值，应选择 BIN/TXT 并勾“处理后”。NPZ 固定保存未滤波的抽取样本。

### 8.4 NPZ 头与到时

归档包含 `data`（int32 二维数组）和 `header`（JSON Unicode 字符串标量），读取使用 `allow_pickle=False`。

| 头字段 | 含义 |
| --- | --- |
| data_type / format_version | 必须为 `eDAS` / 整数 `1`。 |
| dtype / raw_unfiltered | 必须为 `int32` / `true`。 |
| channel_count / frame_count | 实际保存的列数/帧数。 |
| sample_rate_hz | 本文件实际采样率，已计入本次时间抽取。 |
| start_time | 本文件首个保存样本的采集时间；裁剪后相应偏移，未知时 null。 |
| acquisition_start_time | 最初源数据采集起点，重复裁剪时保留，未知时 null。 |
| channel_start / channel_step / channel_numbers | 保存列的原通道起点、间隔及完整列表。 |
| arrivals | 部分保存通道的到时，例如 `{"channel":24,"time_s":0.125}`。 |
| arrival_time_reference | `seconds_from_first_sample`，到时相对本文件首样本计时。 |
| time_downsample / space_downsample | 本次时步/道步。 |
| source_sample_rate_hz / source_files | 本次直接输入的采样率与源文件列表。 |

裁剪后到时会减去输出首样本在输入中的时间偏移；空间抽取移除的通道不保存标记，首样本以前或末个保留样本以后的到时也不保存。到时不强制舍入到新的采样网格，保留原标注时间精度；当前剩余标记顺序也被保存。

重新读取方法：选中 NPZ 所在目录 → 点击 NPZ → 等待加载 → 切换为 Wiggle 查看恢复的红线。显示数据仍会按 Tab1 当前基础滤波设置处理；如需查看未滤波相位，清空滤波后“应用”。NPZ 文件本身的原始整数不受显示处理影响。

完整结构、校验和 Python 读取示例见 [事件到时标注与 NPZ 格式](docs/事件到时标注与NPZ格式.md)。

## 10. 完整使用示例与常见问题

### 10.1 从多文件到带到时的 NPZ

假设文件采样率 2000 Hz，有通道 0～129：

1. 点击“目录”选择目录，用 Shift 选中时间连续的一组文件。
2. 等待加载完成，Tab1 点段填 `0~129`，滤波按需要填 `10~300`，点击“应用”。
3. 如需去噪，打开“去噪处理”逐项执行；处理完成后切为多道波形。
4. 地震道步长设 1，调整增益以辨认波形，Ctrl+点击/拖动标注到时。
5. 悬停通道后 Ctrl+左右键微调；Esc 删除最近错误标记。
6. 在 Tab1 框选需要保存的时间和通道段，选择导出目录、NPZ、时步 2、道步 1。
7. 点击“导出视图”，得到 1000 Hz 的未滤波整数子集以及范围内的到时。
8. 选中导出的 NPZ，切至 Wiggle，核对原通道号和红线。需要保存滤波后数值时另导出 BIN/TXT 并勾“处理后”。

### 10.2 常见问题

| 现象/问题 | 原因与处理 |
| --- | --- |
| 通道超范围或默认分析通道不存在 | 核对文件点数；普通文件从 0 到 N−1。修改 Tab2 的 4,9,14、Tab3 的 4-99、Tab5 的 199～819 等初始值。NPZ 还要核对保存的通道起点与间隔。 |
| 滤波频率报错 | 必须严格在 0～fs/2 之间；低采样率 NPZ 载入后，旧 `10~` 也可能超限。 |
| PSD 无法计算 | 载入/选择的段少于 8 个样本；扩大时间段。PSD窗长是点数，Tab4窗长是秒数。 |
| PSD 看不到低于 10 Hz | 自动横轴在高采样率时通常从 10 Hz 起；显式设置正的 FMin 与所需 FMax。 |
| Wiggle 太密/太慢 | 步长 1 确实画全道；手动增大显示步长或缩小点段。改变显示步长不会自动改变导出道步。 |
| 波形振幅变了但导出没变 | 增益、缩放、填充、限幅是显示参数。只有实际滤波/去噪并选择处理后 BIN/TXT 才改变输出样本。 |
| 切换颜色图后看不到红线 | 到时仅在 Wiggle 显示；切回来恢复。 |
| Ctrl+左右键没有移动标记 | 确认在 Tab1 Wiggle，鼠标悬停实际通道，且该通道已有标记；步幅是 1/fs，较高采样率时很小。 |
| Esc 没有删除到时 | 确认当前为 Tab1 Wiggle 且焦点不在输入框/弹窗；菜单中的 Esc 先关闭菜单。 |
| 相位图/能量图的通道和时间不一致 | 确认当前选择的整组文件已加载、生成图像后没有切换源文件；只选择真实连续且映射一致的数据。 |
| Tab5 “生成能量图”暂时禁用 | 当前文件组还在读取，或未载入有效数据；等待状态栏完成。 |
| 改了时频色阶却没变化 | 取消颜色自动、填完整 V(a~b)，点击“应用颜色条”；若改了计算模式或窗长，则重新绘制。 |
| Tab5 轨迹消失 | 重新生成图像会清除轨迹；先导出 JSON，生成新图后可按需要载入 JSON。 |
| NPZ 缺少某个到时 | 标记通道被导出道步移除，或时间在实际输出首末样本之外；重新检查裁剪窗口和抽取网格。 |
| NPZ/多文件导出仍是未滤波数据 | NPZ 按设计固定原始整数；处理后数值用 BIN/TXT 并勾“处理后”。 |
| 不能读取普通 NPZ 或 TXT | 当前仅接受符合 eDAS 协议的 NPZ；TXT 当前只导出。 |
| 设置与表中默认值不同 | 软件恢复了上次设置；表列的是首次初始值。Tab1 重置也不会重置所有其他页参数。 |
| 当前视图无法导出/与源文件同名 | 确认窗口有有效样本，当前组已加载，目标目录与源文件路径不冲突。 |

## 11. 安装、启动与打包

在项目根目录安装依赖并启动：

```powershell
pip install -r requirements.txt
python run.py
```

核心依赖为 PyQt5、pyqtgraph、NumPy、SciPy。BZ/BZS 可使用 `python-zstandard`；缺失时程序尝试查找可用的 `zstd.dll`。声音播放使用 Windows 后端。

打包：

```powershell
python build_exe.py
```

需要安装 PyInstaller。生成的单文件可执行文件位于 `dist/`，名称前缀为 `eDASpy-`，包含打包日期；有同名文件时添加序号。源码更新后需要重启源码进程，已有旧 exe 需重新打包才包含新功能。

参数自动保存后，下次启动恢复。更换文件时点段会按文件范围夹取；各分析页仍需使用新文件实际存在的通道并重新绘图。Tab1 到时通过 NPZ 保存，Tab5 轨迹通过 JSON/CSV 保存，均不要把参数恢复当作标注文件保存。
