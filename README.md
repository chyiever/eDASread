# eDASread

`eDASread` 是一个面向 `.bin` / `.bz` / `.bzs` 格式 eDAS 数据的桌面程序，提供文件浏览、时空图显示、指定点时域波形联动、滤波预处理、f-k 分析与当前视图导出功能。

## 主要功能

- 扫描并分页浏览目录中的 `.bin` / `.bz` / `.bzs` 文件
- 从文件名解析采样率、点数和时间戳
- 支持 `.bin -> .bz` 批量压缩
- 显示 time-space 图与指定位置点时域波形
- 支持 Tab1 在 time-space 颜色图与多道变面积 Wiggle 剖面间切换显示（振幅缩放、增益、极性、削幅、道抽稀与像素间距、hover 拾取）
- 支持低通、高通、带通滤波
- 支持 Tab1 交互式数据预处理：去尖峰噪声、去共模噪声、去随机噪声、FK 滤波
- 支持 Tab2 指定多通道时域图与 PSD(dB) 绘制
- 支持 Tab3 指定通道范围 f-k 谱绘制
- 支持 Tab4 指定单通道时域波形与短时时频图绘制（对数频率轴）
- 支持 Tab5 交通 DAS 多文件拼接、相位转能量图与人工车辆轨迹折线标注/导出
- 空文件（0 字节）或无完整数据帧的文件会被直接拒绝并给出简洁错误提示
- 支持将指定位置点波形缩放后以声音播放
- 按当前可视窗口导出原始或滤波后的数据

## 主要界面参数说明

### Tab1 数据预处理

- `Point Range`：time-space 图显示的位置点范围，单个输入框填写两个整数 `a~b`（如 `1~1000`），采用 1-based 点号。
- `道间距(m)`：相邻两道之间的物理间距，单位 m，默认 `5`，用于将 y 轴切换为距离显示。
- `第一道位置(m)`：第 1 道对应的物理位置，单位 m，默认 `0`；第 n 道的距离为 `第一道位置 + (n-1) × 道间距`。
- `Y轴显示`：time-space 图 y 轴显示方式，可选 `通道号`（1-based 点号）或 `距离`（物理距离）。
- `距离单位`：距离模式下的单位，可选 `m` 或 `km`；仅当 `Y轴显示` 为 `距离` 时可用。
- `Color Range`：time-space 图颜色范围，单个输入框填写两个浮点数 `a~b`（如 `-0.2~0.2`），单位为 rad；留空表示自动色阶。
- `Colormap`：time-space 图色标，可选 `jet`、`hsv`、`seismic`。
- `滤波(Hz)`：单个输入框表达滤波，`1~`=高通 1 Hz、`~300`=低通 300 Hz、`5k~20k`=带通 5 kHz~20 kHz，支持 `k` 后缀，留空=不滤波。默认 `10~`（高通 10 Hz）。
- `指定位置点时域绘图`：Tab1 上方时域图显示的单个位置点，采用 1-based 点号。
- `播放波形`：播放当前指定位置点的完整波形；播放前会扣除直流、按 99 分位幅值放大并限幅。
- `显示时域图`：勾选/取消控制上方单道时域图；取消勾选时下方时空图或多道图自动占满高度。
- `去尖峰噪声`：参考 DASPy spike removal，使用局部中值检测异常尖峰并按邻近通道插值替换。
- `去共模噪声`：参考 DASPy common-mode removal，估计各通道共有波形并从每个通道中投影扣除。
- `去随机噪声`：参考 DASPy curvelet denoising，使用 curvelet 系数阈值压制随机噪声，计算耗时相对更高。
- `FK滤波`：在 f-k 域压制低视速度能量、保留高视速度成分。
- `DX(m)`：FK 滤波使用的通道间距，单位 m，默认 `5`。
- `VMin / VMax`：FK 滤波速度过渡窗，单位 m/s，默认 `800-1200`；低于 `VMin` 的视速度成分被压制，高于 `VMax` 的成分被保留，中间为余弦过渡。
- `Save Filtered Data`：导出当前处理后矩阵的可视窗口切片；如果未勾选，则从原始文件导出当前窗口。
- `Save as txt`：将导出格式改为文本矩阵，单位为 rad。
- `图类型`：Tab1 下方绘图模式，可选 `时空颜色图`（默认）或 `多道波形(Wiggle)`。选择 Wiggle 后显示独立的“波形变面积参数”分组（见下）。
- `波形变面积参数`（仅 Wiggle 模式显示）：
  - `振幅缩放`：波形振幅归一化方式，可选 `全局最大值` / `三道最大值` / `单道最大值` / `全局均方根` / `三道均方根` / `单道均方根` / `全局平均值`；“三道”为当前道及其相邻两道共 3 道的窗口归一化。
  - `增益(dB)`：-60~60 dB 整体增益；窄滑动条（约原 1/6 宽）+ `−`/`+` 微调按钮（±5 dB）+ 数字框同步，实时生效。
  - `负向翻转`：勾选后反转波形极性（默认未勾选）。
  - `振幅范围`：超过该显示振幅的波峰被削平，`0` 表示不限幅。
  - `填充`：开启变面积黑色填充；`负向填充` 勾选后正负振幅都填充，否则只填充正振幅。
  - `邻道间隔`：`地震道`（每 N 道绘制 1 道）或 `像素点`（相邻基线像素间距），`间隔值` 输入对应 N 或 P。
  - 剖面纵向为道号（自下而上递增，可用 `Y轴显示` 切换为距离），横向为时间；支持鼠标平移、滚轮缩放、框选放大、键盘 ↑/↓ 纵向平移，鼠标悬停时在状态栏显示 道号/距离/时间/振幅。Wiggle 模式下上方单道时域图与下方剖面宽度对齐。

### Tab2 通道时域/PSD

- `通道`：需要绘制的通道列表，采用 1-based 点号，可输入 `5,10,15`，也支持空格、中文逗号或分号分隔。
- `PSD窗长`：Welch PSD 的每段采样点数；填写整数时手动指定，填写 `auto` 或留空时自动取 `min(max(256, 采样率), 4096, 数据长度)`。
- `重叠(%)`：Welch PSD 相邻窗口重叠比例，范围 `[0, 100)`，默认 `50`。
- `FMin / FMax`：PSD 图 x 轴频率显示范围，单位 Hz；两者同时填写才生效，留空或 `auto` 表示自动范围。
- `PSD Min / PSD Max`：PSD 图 y 轴显示范围，单位 dB；两者同时填写才生效，留空或 `auto` 表示自动范围。
- 时域图会对每个通道扣除自身中位数，并自动施加不同垂直偏移，避免多条波形重叠。
- PSD 计算使用 `scipy.signal.welch()`，显示单位为 dB：`10 * log10(power + eps)`。

### Tab3 f-k谱

- `通道范围`：用于计算 f-k 谱的连续通道范围，采用 1-based 点号，格式如 `5-100`。
- `间距(m)`：通道间距，单位 m，用于计算空间频率轴。
- `空间taper`：空间方向 Tukey taper 比例，范围 `0-1`，默认 `0`。
- `时间taper`：时间方向 Tukey taper 比例，范围 `0-1`，默认 `0.05`。
- `NFFT-K`：空间方向 FFT 点数；填写整数时手动指定，必须不小于通道数；填写 `auto` 或留空时自动取不小于通道数的 2 的幂。
- `NFFT-T`：时间方向 FFT 点数；填写整数时手动指定，必须不小于采样点数；填写 `auto` 或留空时自动取不小于采样点数的 2 的幂。
- `F(a~b)`：f-k 谱 y 轴频率显示范围，单个输入框填写 `a~b`（单位 Hz），留空或 `auto~auto` 表示自动范围。
- `K(a~b)`：f-k 谱 x 轴空间频率显示范围，填写 `a~b`（单位 cycles/m），留空或 `auto~auto` 表示自动范围。
- `V(dB)`：f-k 谱颜色显示范围，填写 `-20~0`。
- `扣除背景`：按每个频率扣除空间频率方向的中位背景，使相对能量更突出；默认开启。
- Tab3 使用 Tab1 当前处理后的数据，不重新读取原始文件，也不重新执行 Tab1 的滤波或去噪。

### Tab4 时域/时频

- `通道`：需要绘制的单个通道，采用 1-based 点号。
- `滤波(A~B)`：在 Tab1 处理后数据的基础上，对所选通道进一步滤波，格式与 Tab1 相同（`A~`高通 / `~B`低通 / `A~B`带通，支持 `k` 后缀），留空=不滤波。
- `Colormap`：颜色条支持 jet、viridis、inferno、plasma、magma、turbo、hsv、seismic。取消 `颜色自动` 后填写 `V(a~b)`，点击 `应用颜色条` 即可更新现有图，不需要重新计算时频谱。
- `模式`：时频数值类型，可选 `PSD`（功率谱密度，`scaling="density"`）或 `Amplitude`（幅值谱，`scaling="spectrum"`）。
- `数值`：颜色数值标度，可选 `Log`（PSD 按 `10*log10`、Amplitude 按 `20*log10`）或 `Linear`。
- `窗长(s)`：短时谱的窗口长度，单位 s，对应 `nperseg = round(窗长 × 采样率)`，限制在 `[8, 采样点数]`，默认 `0.01`。
- `重叠(%)`：相邻窗口重叠比例，范围 `[0, 100)`，默认 `50`。
- `F(a~b)`：时频图 y 轴频率显示范围，单个输入框填写 `a~b`（单位 Hz），留空或 `auto~auto` 表示自动范围。
- `V(a~b)`：时频图颜色范围；勾选 `颜色自动` 时按数据分位数自动设置，取消勾选时填写 `a~b`。
- `显示窗口(s)`：绘制完成后默认显示的时间段长度，默认 `0.1`；填写 `auto` 或留空时显示完整时长。
- Tab4 使用 Tab1 当前处理后的数据，不重新读取原始文件，也不重新执行 Tab1 的滤波或去噪。

### Tab5 车辆轨迹标记

- 在左侧文件列表中用 Ctrl/Shift 多选按时间连续的数据文件，程序按文件时间/名称排序后沿时间轴拼接；Tab5 使用当前拼接数据。
- `图像类型` 可在 `能量图` 和 `相位图` 间切换。相位图直接显示与 Tab1 相同的已拼接相位数据；能量图在同一数据基础上继续执行交通 DAS 预处理和 Hilbert 包络转换。两种图都使用横轴时间、纵轴绝对通道号，并支持轨迹标记。
- 设置 1-based 通道起止范围、带通上下限、是否去共模、时间降采样倍数和通道均衡方式，然后点击 `生成能量图`。
- Tab5 右侧显示独立能量颜色条；支持 inferno、viridis、plasma、magma、jet、turbo。保持 `颜色自动` 可使用稳健分位范围，或取消勾选并输入 VMin/VMax 后点击 `应用颜色条`，无需重新生成能量图。
- 能量图流程与 `das_vehicle_trajectory_detection.ipynb` 3.2 节一致：Hilbert 包络、时间块平均降采样、逐通道时间中位数基线扣除并截断为非负、P99.9（或 MAD）通道增益均衡。默认在此之前执行 0.05–10 Hz 带通与去共模。
- 多文件数据在内部按 `(time, channel)` 的时间维拼接，显示时转为“横轴时间、纵轴绝对通道号”；图标题同时显示完整拼接时长、通道范围和源文件数量，便于核对拼接结果。
- 在能量图中依次左键点击起点、可选的若干中间点和结束点，点击 `完成当前轨迹` 后形成一条直线或折线；一幅图可保存多条轨迹。
- `撤销当前点` 或 `Ctrl+Z` 只影响尚未完成的轨迹；轨迹列表支持删除所选轨迹或清空全部轨迹。列表中勾选的轨迹显示，取消勾选则隐藏，但不会删除标注。Ctrl+左键拖动用于框选放大，右键拖动平移，滚轮缩放。
- 可导出 JSON 或 CSV。JSON 记录源文件、坐标定义、能量图等效采样率、通道范围及每条轨迹的全部顶点，并可重新载入继续编辑；CSV 适合后续统计和训练数据整理。
- 多文件切换或拼接读取期间，Tab5 会暂时禁用 `生成能量图`；只有最新选择的整组文件加载完成后才允许生成，防止把上一组数据误标为当前文件组。
- 时频计算使用 `scipy.signal.spectrogram()`（Hann 窗），线性频率谱会重采样到等间距 `log10(f)` 网格后再显示，y 轴标签直接显示真实频率（Hz），并采用科学计数法（如 `10³`）标注。
- 上方时域图与下方时频图的 x 轴双向联动：任一子图矩形放大或平移，另一子图自动切换到相同时间范围；键盘左右键按最近点击的子图水平平移。

Tab2 和 Tab3 的绘图区支持鼠标滚轮缩放、拖动平移和框选放大，方便查看局部时窗、频段或波数范围。

## 目录说明

- `scripts/`：主程序与界面、渲染、处理逻辑
- `assets/`：程序图标等静态资源
- `docs/`：用户手册与开发文档
- `singledataread/`：单文件读取与示例 Notebook
- `bin2segy/`：bin 数据转 segy 的相关脚本
- `run.py`：项目根目录启动入口
- `build_exe.py`：根目录打包脚本（输出到 `dist/`）
- `requirements.txt`：运行时依赖清单

## 运行环境

推荐依赖（完整清单见 `requirements.txt`）：

```bash
pip install -r requirements.txt
```

核心运行时依赖：

- `PyQt5`：界面框架
- `pyqtgraph`：绘图
- `numpy`：数值计算
- `scipy`：信号滤波与频谱分析
- `python-zstandard`：可选，`.bz/.bzs` 压缩格式支持（缺失时尝试加载 `zstd.dll`）

启动方式（项目根目录）：

```bash
python run.py
```

打包单文件 EXE（项目根目录，exe 名自动包含打包日期，构建完成后自动清理 `build/` 等临时文件）：

```bash
python build_exe.py
```

## 数据规则

- 文件名应包含 `-xxxHz-` 和 `-xxxpt-`
- 二进制数据类型为 `int32`
- 数据组织方式为 `frame_count x points`
- 存储顺序为 frame-major
