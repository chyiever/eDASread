# eDASpy 参数输入框默认值与输入范围说明

本文档汇总 eDASpy 各 Tab 参数输入框的**默认值**与**允许输入的数值范围**，便于用户判断合法输入，并供后续维护时核对修改。

一般约定：

- 只有明确支持的输入框才能留空/填写 `auto`，具体见各参数说明。完整操作与生效方式见 [README](../README.md)。
- 通道号一律使用 **0-based**（第一个位置点为 0，有 N 个位置点时有效编号为 0～N−1）。
- 多个范围参数必须成对填写（最小值 + 最大值），否则报错。
- 本文档依据 `scripts/ui/control_panel.py`、`scripts/render/analysis_views.py`、`scripts/render/traffic_trajectory_view.py` 与 `scripts/ui/main_window.py` 中的校验逻辑整理。

## Tab1 数据预处理（`ControlPanel`）

| 参数 | 默认值 | 允许范围 | 说明 |
| --- | --- | --- | --- |
| Point Range | `0~99` | 两个整数 `a~b`，`a ≤ b`，两端为当前文件实际存在的通道号 | 显示点段范围（普通文件为 0～N−1）；NPZ 使用保存的通道起点/步长映射。加载新文件时按实际范围夹取。 |
| Color Range | `-0.4~0.4` | 两个有限浮点数 `a~b`，a<b；完整填写两端 | time-space 图颜色范围（rad）。 |
| Colormap | `seismic` | 下拉：`jet` / `hsv` / `seismic` | 颜色表。 |
| Y轴显示 | `通道号` | 下拉：`通道号` / `距离` | y 轴显示模式；选择“距离”时按“首道位置 + 通道号×道间距”换算。 |
| 距离单位 | `m` | 下拉：`m` / `km` | 仅在“距离”模式下启用。 |
| 图类型 | `时空颜色图` | 下拉：`时空颜色图` / `多道波形(Wiggle)` | Tab1 下方绘图模式；Wiggle 为多道变面积波形剖面。 |
| 道间距(m) | `5` | 浮点数 `0.001 ~ 1000000`，最多 3 位小数 | 相邻两个位置点的间距，须大于 0。 |
| 首道位置(m) | `0` | 浮点数 `-1×10⁶ ~ 1×10⁶`，最多 3 位小数 | 通道 0 对应的物理位置，可为负。 |
| 滤波(Hz) | `10~` | 见右侧格式说明 | 单个输入框表达滤波：`A~`=高通 A Hz；`~B`=低通 B Hz；`A~B`=带通 A~B Hz；支持 `k` 后缀（如 `5k~20k`）；留空/`none`=不滤波。 |
| 波形点 | `0` | 整数，动态范围 `[Point Range]` | 指定位置点时域波形/播放用通道；滚轮按一个实际保存通道步长移动。 |
| DX(m)（FK） | `5` | 浮点数 `0.001 ~ 1000000`，最多 3 位小数 | FK 滤波通道间距。 |
| VMin（FK） | `800` | 浮点数 `0.001 ~ 1000000`，最多 3 位小数 | FK 滤波速度下限（m/s），须小于 VMax。 |
| VMax（FK） | `1200` | 浮点数 `0.001 ~ 1000000`，最多 3 位小数 | FK 滤波速度上限（m/s），须大于 VMin。 |
| 显示时域图 | 勾选 | 复选 | 显示/隐藏上方单道时域图；隐藏时下方时空图或多道图自动占满高度。 |
| Export folder | 空 | 任意有效目录路径 | 导出目录（Browse Export 选择）。 |
| Save Filtered Data | 未勾选 | 复选 | BIN/TXT 勾选后导出处理后数据，否则导出原始数据。NPZ 固定原始数据，此选项禁用。 |
| 导出格式 | `BIN` | `BIN` / `TXT` / `NPZ` | 替代 Save as txt；NPZ 保存未滤波 int32、eDAS 头信息及到时。 |
| 时间步长 | `1` | 正整数 `1~1000000` | 按步长直接抽取，实际采样率 = 输入采样率/步长。 |
| 空间步长 | `1` | 正整数 `1~1000000` | 在裁剪后的列范围内直接抽取，NPZ 保留原通道号及累计通道间隔。 |
| 清除到时 | 按钮 | 当前文件组 | 删除当前文件组全部到时标记。 |


### 波形变面积参数（`图类型` 选 `多道波形(Wiggle)` 时显示）

| 参数 | 默认值 | 允许范围 | 说明 |
| --- | --- | --- | --- |
| 振幅缩放 | `全局最大值` | 下拉：`全局最大值` / `三道最大值` / `单道最大值` / `全局均方根` / `三道均方根` / `单道均方根` / `全局平均值` | 每道波形振幅归一化方式；“三道”表示按该道与相邻两道组成的 3 道窗口归一化。 |
| 增益(dB) | `0` | 整数 `-60 ~ 60`（滑动条、`−`/`+` 按键与输入框同步） | 整体振幅增益，计算公式 `10^(dB/20)`；`−`/`+` 每次步进 5 dB。 |
| 负向翻转 | 未勾选 | 复选 | 反转全部波形极性（默认未勾选）。 |
| 振幅范围 | `0` | 浮点数 `≥ 0`；`0` 表示不限幅 | 超过该显示振幅的波峰被削平（clip）。 |
| 填充 | 勾选 | 复选 | 开启变面积黑色填充。 |
| 负向填充 | 未勾选 | 复选 | 勾选时正负振幅都填充，否则只填充正振幅。 |
| 邻道间隔 | `地震道` | 下拉：`地震道` / `像素点` | 相邻两道显示间隔模式。 |
| 间隔值 | `1` | `地震道`：整数 `≥ 1`（每 N 列绘制 1 道，1 绘制全部选中通道，无隐式 150 道限制）；`像素点`：浮点数 `> 0`（相邻基线像素间距） | 道抽稀或像素间距。 |

## 说明与维护建议

- 所有“下拉框”之外的数值输入框均受输入校验器约束（如 Tab1 的 `QDoubleValidator`），非法字符无法输入；但“范围类”约束（如 VMin < VMax、[0,100) 等）在点击 Apply/绘制/生成时由 `main_window.py` 校验并弹出提示。
- 若修改校验逻辑，请同步更新本文档。
- 通道/点号上限随当前数据文件点数（`metadata.points`）动态变化。

## 编号迁移与数量约定

范围终点包含在内，`0~99` 对应 100 个位置点。自动显示上限为前 100 个点（终点 99），不足时使用文件最后一个编号 N−1；单点文件的有效范围为 `0~0`。旧版已保存的通道参数一次性减 1 后写入编号版本，后续启动不再重复转换。通道编号变化不改变文件点数、通道间隔、采样率或数据内容。轨迹 JSON v2 使用 `0_based_channel`，旧版 v1 JSON 自动减 1；历史 CSV 需手动换算。


## 到时与裁剪 NPZ 的通道映射

Tab1 多道波形：Ctrl+左键标注，Ctrl+左键拖动连续标注，悬停通道后 Ctrl+←/→ 按 1/采样率秒微调。每个通道保存一个到时。NPZ 导入后使用保存的原通道号，例如通道起点 20、步长 2、三列数据对应 20/22/24，通道范围和波形点必须输入实际保留的通道号。此前表格中的 0～N−1 是普通未裁剪原始文件的默认映射。道间距仍表示原始相邻通道的间距。

格式及时间参考见 [事件到时标注与 NPZ 格式](事件到时标注与NPZ格式.md)。


## 紧凑布局与快捷键补充（2026-10-16）

Tab1 常用参数/操作/导出共三行，Wiggle 另加一行；道间距、首道位置、Y 轴模式及单位移入“坐标设置”，去噪与 FK 参数移入“去噪处理”。控件数值与持久化逻辑不变。Tab2～Tab5 参数采用两行可读排布。

Esc 每次删除最近修改通道的当前到时，长按连续删除至空；不恢复该通道旧的时间值。菜单、对话框和输入编辑不触发标记删除。窗口名称与主题统一为 eDAS数据处理软件（eDASpy ）。


## 全局设置

标题栏右上角“设置”→“界面文字大小”：默认 **18px**，整数 **12～28px**。点击“应用”立即生效并保存，“确定”同时关闭；“取消”不应用尚未提交的修改；“恢复默认”先将输入值改为 18px，需再应用。字号同时作用于控件、坐标和色条，参数区过宽时横向滚动。
