# eDASread 参数输入框默认值与输入范围说明

本文档汇总 eDASread 各 Tab 参数输入框的**默认值**与**允许输入的数值范围**，便于用户判断合法输入，并供后续维护时核对修改。

一般约定：

- 输入框留空或填写 `auto` 通常表示“自动计算/全范围”，具体见各参数说明。
- 通道号一律使用 **1-based**（第 1 道为 1）。
- 多个范围参数必须成对填写（最小值 + 最大值），否则报错。
- 本文档依据 `scripts/ui/control_panel.py`、`scripts/render/analysis_views.py`、`scripts/render/traffic_trajectory_view.py` 与 `scripts/ui/main_window.py` 中的校验逻辑整理。

## Tab1 数据预处理（`ControlPanel`）

| 参数 | 默认值 | 允许范围 | 说明 |
| --- | --- | --- | --- |
| Point Range | `1~100` | 两个整数 `a~b`，`1 ≤ a ≤ b ≤ 100000` | 显示点段范围（1-based）。加载文件后若超出该文件点数会被夹取到 `[1, 文件点数]`。 |
| Color Range | `-0.4~0.4` | 两个浮点数 `a~b`（`-1000 ~ 1000`，最多 3 位小数）；留空表示自动色阶 | time-space 图颜色范围（rad）。 |
| Colormap | `seismic` | 下拉：`jet` / `hsv` / `seismic` | 颜色表。 |
| Y轴显示 | `通道号` | 下拉：`通道号` / `距离` | y 轴显示模式；选择“距离”时按“第一道位置 + (通道号-1)×道间距”换算。 |
| 距离单位 | `m` | 下拉：`m` / `km` | 仅在“距离”模式下启用。 |
| 图类型 | `时空颜色图` | 下拉：`时空颜色图` / `多道波形(Wiggle)` | Tab1 下方绘图模式；Wiggle 为多道变面积波形剖面。 |
| 道间距(m) | `5` | 浮点数 `0.001 ~ 1000000`，最多 3 位小数 | 相邻两个位置点的间距，须大于 0。 |
| 首道位置(m) | `0` | 浮点数 `-1×10⁶ ~ 1×10⁶`，最多 3 位小数 | 第 1 道对应的物理位置，可为负。 |
| 滤波(Hz) | `10~` | 见右侧格式说明 | 单个输入框表达滤波：`A~`=高通 A Hz；`~B`=低通 B Hz；`A~B`=带通 A~B Hz；支持 `k` 后缀（如 `5k~20k`）；留空/`none`=不滤波。 |
| 波形点 | `1` | 整数，动态范围 `[Point Range]` | 指定位置点时域波形/播放用通道；滚轮可步进 1。 |
| DX(m)（FK） | `5` | 浮点数 `0.001 ~ 1000000`，最多 3 位小数 | FK 滤波通道间距。 |
| VMin（FK） | `800` | 浮点数 `0.001 ~ 1000000`，最多 3 位小数 | FK 滤波速度下限（m/s），须小于 VMax。 |
| VMax（FK） | `1200` | 浮点数 `0.001 ~ 1000000`，最多 3 位小数 | FK 滤波速度上限（m/s），须大于 VMin。 |
| 图类型 | `时空颜色图` | 下拉：`时空颜色图` / `多道波形(Wiggle)` | Tab1 下方绘图模式；Wiggle 为多道变面积波形剖面。 |
| 显示时域图 | 勾选 | 复选 | 显示/隐藏上方单道时域图；隐藏时下方时空图或多道图自动占满高度。 |
| DX(m)（FK） | `5` | 浮点数 `0.001 ~ 1000000`，最多 3 位小数 | FK 滤波通道间距。 |
| VMin（FK） | `800` | 浮点数 `0.001 ~ 1000000`，最多 3 位小数 | FK 滤波速度下限（m/s），须小于 VMax。 |
| VMax（FK） | `1200` | 浮点数 `0.001 ~ 1000000`，最多 3 位小数 | FK 滤波速度上限（m/s），须大于 VMin。 |
| Export folder | 空 | 任意有效目录路径 | 导出目录（Browse Export 选择）。 |
| Save Filtered Data | 未勾选 | 复选 | 勾选后导出滤波结果，否则导出原始数据。 |
| Save as txt | 未勾选 | 复选 | 勾选后导出为文本（`frames x points`，单位 rad）。 |

### 波形变面积参数（`图类型` 选 `多道波形(Wiggle)` 时显示）

| 参数 | 默认值 | 允许范围 | 说明 |
| --- | --- | --- | --- |
| 振幅缩放 | `全局最大值` | 下拉：`全局最大值` / `三道最大值` / `单道最大值` / `全局均方根` / `三道均方根` / `单道均方根` / `全局平均值` | 每道波形振幅归一化方式；“三道”表示按该道与相邻两道组成的 3 道窗口归一化。 |
| 增益(dB) | `0` | 整数 `-60 ~ 60`（滑动条、`−`/`+` 按键与输入框同步） | 整体振幅增益，计算公式 `10^(dB/20)`；`−`/`+` 每次步进 5 dB。 |
| 负向翻转 | 未勾选 | 复选 | 反转全部波形极性（默认未勾选）。 |
| 振幅范围 | `0` | 浮点数 `≥ 0`；`0` 表示不限幅 | 超过该显示振幅的波峰被削平（clip）。 |
| 填充 | 勾选 | 复选 | 开启变面积黑色填充。 |
| 负向填充 | 未勾选 | 复选 | 勾选时正负振幅都填充，否则只填充正振幅。 |
| 邻道间隔 | `地震道` | 下拉：`地震道` / `像素点` | 相邻两道显示间隔模式。 |
| 间隔值 | `1` | `地震道`：整数 `≥ 1`（每 N 道绘制 1 道）；`像素点`：浮点数 `> 0`（相邻基线像素间距） | 道抽稀或像素间距。 |

## Tab2 通道时域/PSD（`ChannelAnalysisView`）

| 参数 | 默认值 | 允许范围 | 说明 |
| --- | --- | --- | --- |
| 通道 | `5,10,15` | 逗号分隔的整数列表，每个通道 `1 ~ 文件点数` | 需要绘制的通道号。 |
| PSD窗长 | `auto` | 整数 `≥ 8`，或 `auto`/留空 | Welch 每段长度（nperseg）。 |
| 重叠(%) | `50` | 浮点数 `[0, 100)` | PSD 分段重叠比例。 |
| FMin / FMax | 空（auto） | 浮点数 `≥ 0`，且 FMin < FMax | PSD 横轴（Hz）显示范围。 |
| PSD Min / PSD Max | 空（auto） | 浮点数，且 Min < Max | PSD 纵轴（dB）显示范围。 |

## Tab3 f-k 谱（`FkSpectrumView`）

| 参数 | 默认值 | 允许范围 | 说明 |
| --- | --- | --- | --- |
| 通道范围 | `5-100` | 格式 `起点-终点`，整数，`1 ≤ 起点 ≤ 终点 ≤ 文件点数` | 参与 f-k 计算的通道区间。 |
| 间距(m) | `5` | 浮点数 `> 0` | 通道间距。 |
| 空间taper | `0` | 浮点数 `[0, 1]` | 空间维 Tukey taper 比例。 |
| 时间taper | `0.05` | 浮点数 `[0, 1]` | 时间维 Tukey taper 比例。 |
| NFFT-K | `auto` | 整数 `≥ 2`，或 `auto` | f-k 谱相干叠加的空间维 FFT 长度。 |
| NFFT-T | `auto` | 整数 `≥ 2`，或 `auto` | 时间维 FFT 长度。 |
| F(a~b) | `auto~auto` | 两个浮点数 `a~b`（`≥ 0`，a < b）；留空/`auto` | 频率显示/滤波范围（Hz）。 |
| K(a~b) | `auto~auto` | 两个浮点数 `a~b`（a < b）；留空/`auto` | 波数显示/滤波范围（cycles/m），可为负。 |
| V(dB) | `-20~0` | 两个浮点数 `a~b`（a < b） | 谱图颜色范围（dB）。 |
| 扣除背景 | 勾选 | 复选 | 显示前减去背景基线。 |

## Tab4 时域/时频（`TimeFrequencyAnalysisView`）

| 参数 | 默认值 | 允许范围 | 说明 |
| --- | --- | --- | --- |
| 通道 | `1` | 整数 `1 ~ 文件点数` | 要分析的通道号。 |
| 滤波(A~B) | 空（none） | 与 Tab1 相同格式：`A~`高通 / `~B`低通 / `A~B`带通，支持 `k` 后缀 | Tab4 内附加滤波。 |
| 模式 | `PSD` | 下拉：`PSD` / `Amplitude` | 时频图数值类型。 |
| 数值 | `Log` | 下拉：`Log` / `Linear` | 时频图数值刻度；Log 时色标单位为 dB。 |
| 窗长(s) | `0.01` | 浮点数 `> 0` | spectrogram 窗长，内部 `nperseg = round(窗长 × 采样率)` 并夹取到 `[8, trace长度]`。 |
| 重叠(%) | `50` | 浮点数 `[0, 100)` | 时频分段重叠比例。 |
| F(a~b) | `auto~auto` | 两个浮点数 `> 0`，a < b | 时频图纵轴频率显示范围（Hz）。 |
| V(a~b) | `auto~auto` | 两个浮点数，a < b | 时频图颜色范围；关闭“颜色自动”时须填写。 |
| 显示窗口(s) | `0.1` | 浮点数 `> 0`，或 `auto`/留空 | 绘图后默认显示的时间窗口；auto/留空显示完整时长。 |
| Colormap | `jet` | 下拉：`jet` / `viridis` / `inferno` / `plasma` / `magma` / `turbo` / `hsv` / `seismic` | 颜色表。 |
| 颜色自动 | 勾选 | 复选 | 勾选时自动设置 V(a~b)。 |

## Tab5 车辆轨迹标记（`TrafficTrajectoryView`）

| 参数 | 默认值 | 允许范围 | 说明 |
| --- | --- | --- | --- |

| 去共模 | 勾选 | 复选 | 能量模式下是否去除共模噪声。 |

## 说明与维护建议

- 所有“下拉框”之外的数值输入框均受输入校验器约束（如 Tab1 的 `QDoubleValidator`），非法字符无法输入；但“范围类”约束（如 VMin < VMax、[0,100) 等）在点击 Apply/绘制/生成时由 `main_window.py` 校验并弹出提示。
- 若修改校验逻辑，请同步更新本文档。
- 通道/点号上限随当前数据文件点数（`metadata.points`）动态变化。
