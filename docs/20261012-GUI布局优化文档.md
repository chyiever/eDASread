# 20261012 - GUI 布局优化文档

## 一、背景与目标

原 Tab1 参数区占用 4~5 行，各参数输入框宽度不等、存在大量冗余拉伸，挤占绘图区高度。本次优化目标：

- 参数集中到 **2 行**，并集中在 `Apply` 按钮上方；
- 同一 Tab 内所有输入框**等宽、等间距**，消除不等宽与冗余；
- 其他 Tab（Tab2/Tab3/Tab5）按同样原则整理；Tab4 已是两行紧凑布局，仅核对未做改动。

参考依据：开放式编码 agent 的 Qt GUI Design skill（qt-ui-design）——统一对齐、等宽输入控件、同一分组就近排列（Proximity/Similarity）、减少每屏选项密度，仅规律地打破布局（von Restorff 效应）。

## 二、Tab1 参数区（scripts/ui/control_panel.py）

### 2.1 布局结构（改动前 vs 改动后）

改动前 `Tab1 Parameters` 为 `QGridLayout` 3 列网格，实际占用 5 行：

| 行 | 内容 |
| --- | --- |
| 0 | Point Range、Color Range、Colormap（跨列） |
| 1 | 道间距、第一道位置、Y轴显示、距离单位 |
| 2 | Apply / Reset / Reset View / Back View / Zoom Out 2x |
| 3 | 滤波 Type/Cutoff + 指定位置点时域绘图行 |
| 4 | 导出区 |

改动后为 2 个参数行 + 1 个按钮行 + 1 个导出行，共 4 行。每个参数为一个“标签在上、输入框在下”的等宽单元格：

```
第 1 行：Point Start | Point End | VMin | VMax | Colormap | Y轴显示 | 距离单位
第 2 行：道间距(m)  | 首道位置(m) | 滤波 | 低频(Hz) | 高频(Hz) | 波形点 | 图类型
第 3 行：Apply | Reset | Reset View | Back View | Zoom Out 2x | 播放波形
第 4 行：导出区（路径 + 浏览 + 导出 + 两个复选项）
```

右侧第 0~1 行保留 4 个去噪按钮列，第 3 行右侧放 FK 参数（`DX(m)/VMin/VMax`）。

### 2.2 尺寸统一

| 控件类型 | 固定宽度 | 说明 |
| --- | --- | --- |
| 数字输入框（QLineEdit） | 86 px | 统一等宽 |
| 下拉框（QComboBox） | 96 px | 统一等宽 |
| FK 参数（DX/VMin/VMax） | 80 px | 独立行内等宽 |
| 按钮 | 最小 105 px | Apply 一行 6 个按钮等分伸展 |

- 网格每列 `setColumnStretch(1)` 等分，固定宽度控件居中，列间多余宽度均匀分布。
- 空间不再随内容膨胀，原“宽度冗余”消失。

### 2.3 代码变更

- 删除不再使用的 `_build_labeled_pair_row`、`_build_multi_widget_row`。
- 新增 `_build_parameter_grid(*rows)` 与 `_build_parameter_cell(label, widget)`：
  - `_build_parameter_grid` 把若干行（每行若干 `(标签, 控件)`）排成等宽网格；
  - `_build_parameter_cell` 生成“标签在上、控件在下”的单元格，并统一 `setFixedWidth`。
- 导出区、去噪按钮、控制按钮行保持原有逻辑，仅调整网格行列位置。
- Tab1 高度由此缩小约 1 行（参数 2 行 + 按钮 1 行 + 导出 1 行）。

## 三、其他 Tab 的同类优化

### 3.1 Tab2 通道时域/PSD（scripts/render/analysis_views.py，ChannelAnalysisView）

- 布局原本已是 2 行；本次为 7 个输入框统一固定宽度：`通道` = 180 px，其余（PSD窗长/重叠/FMin/FMax/PSD Min/Max）= 84 px。
- 行列 stretch 权重不改，等宽后列宽由内容自然对齐。

### 3.2 Tab3 f-k 谱（scripts/render/analysis_views.py，FkSpectrumView）

- 原为 3 行网格（2 行参数 + 1 行参数/按钮），改为 **2 行 × 7 列** 等宽网格：

```
第 1 行：通道范围 | 间距(m) | 空间taper | 时间taper | NFFT-K | NFFT-T | 扣除背景
第 2 行：FMin | FMax | KMin | KMax | VMin(dB) | VMax(dB) | 绘制 f-k 谱
```

- 输入框 88 px、下拉框 110 px、复选框/按钮固定等宽；复用新增模块函数 `_uniform_param_cell()`。

### 3.3 Tab5 车辆轨迹标记（scripts/render/traffic_trajectory_view.py）

- 原为 3 行 × 4 列的“标签-输入”对，改为 **2 行 × 7 列** 标签在上等宽网格：

```
第 1 行：图像类型 | 通道起点 | 通道终点(含) | 低频(Hz) | 高频(Hz) | 降采样 | 通道均衡
第 2 行：Colormap | VMin | VMax | 颜色自动 | 去共模 | 应用颜色条 | 生成能量图
```

- 所有控件统一 `Times New Roman 10pt`；输入框 96 px、下拉框 110 px；新增模块函数 `_uniform_param_cell()`。

### 3.4 Tab4 时域/时频

- 已有 2 行紧凑布局（数值输入框 80 px、下拉框 100 px），本次未改动。

## 四、布局原则（对应 qt-ui-design 设计要点）

| 原则 | 应用 |
| --- | --- |
| 等宽输入 / 统一对齐 | 所有数字框固定 80~96 px，标签顶部居中 |
| Uniform Connectedness / Proximity | 显示参数、预处理、导出分为不同颜色分组并就近排列 |
| 少即是多（Ockham） | 参数两行排布，删除冗余宽度 |
| 渐进披露（Progressive Disclosure） | Wiggle 专用参数收进独立分组，仅在切到 Wiggle 模式时显示 |

## 六、20261012 第二轮优化：参数区进一步压缩

### 6.1 目标

用户反馈参数区仍占较大垂直空间。本轮再次压缩：

- 参数名与输入框**放在同一行**（标签在左、输入框在右），不再使用“标签在上”；
- Tab1 合并三组常用参数为**单个输入框**；
- Tab2/3/4/5 参数**全部调整为 1 行**，参数之间保持间距。

### 6.2 Tab1 合并输入框

| 合并项 | 输入格式 | 说明 |
| --- | --- | --- |
| Point Range | `1~1000` | 两个整数 `a~b`，合并原 Point Start/Point End |
| Color Range | `-0.2~0.2` | 两个浮点数 `a~b`，合并原 VMin/VMax；留空=自动色阶 |
| 滤波(Hz) | `1~`（高通 1 Hz） / `~300`（低通 300 Hz） / `5k~20k`（带通） | 合并原 滤波下拉 + Low Cut + High Cut；支持 `k` 后缀，空=不滤波 |

内部保留原分项控件（`point_start_edit`/`point_end_edit`、`vmin_edit`/`vmax_edit`、`filter_type_combo`/`low_cut_edit`/`high_cut_edit`）作为逻辑载体，由 `_sync_merged_to_parts()` / `refresh_merged_edits()` 双向同步；主窗口所有读取/校验/导出逻辑保持不变，仅持久化键改为 `tab1/point_range`、`tab1/color_range`、`tab1/filter`。

### 6.3 Tab1 布局（改造后）

```
第 1 行：Point Range [1~100] | Color Range [-0.4~0.4] | Colormap | Y轴显示 | 距离单位 | 图类型
第 2 行：道间距(m) | 首道位置(m) | 滤波(Hz)[10~] | 波形点
第 3 行：Apply | Reset | Reset View | Back View | Zoom Out 2x | 播放波形
第 4 行：导出
（右侧去噪按钮 + FK 参数不变）
```

由于改为“标签-输入框同一行”，每行高度由 ~50 px 降为 ~28 px，整体垂直占用显著减小。

### 6.4 Tab2/3/4/5 全部单行化

- Tab2 通道时域/PSD：7 个输入 + 绘制按钮排成 1 行。
- Tab3 f-k 谱：12 个输入 + 扣除背景复选 + 绘制按钮排成 1 行（输入框统一 56~96 px）。
- Tab4 时域/时频：16 个控件 + 2 个按钮排成 1 行。
- Tab5 轨迹：10 个输入 + 2 复选 + 2 按钮排成 1 行。
- 所有 Tab 参数组高度均为 1 行；标签保留原语义，输入框固定等宽保证对齐。

### 6.5 其他配套调整

- Wiggle 增益滑动条缩窄到 70 px（约为原来 1/6），并新增 `−`/`+` 两个 24 px 微调按钮（±5 dB）。
- Wiggle 模式隐藏直方图颜色条时，同时隐藏上方时域图右侧的 150 px 占位，使上下两图宽度一致。
- 修复多道波形重建时的 `slice_rms` 平方缺失导致的 `invalid value in sqrt` 告警。
