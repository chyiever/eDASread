# 20261012 - 波形变面积 Wiggle 剖面开发文档

## 一、需求

为 Tab1 增加一个显示切换选项：**time-space 颜色图** 或 **多道波形（变面积 Wiggle）图**，默认前者。Wiggle 模式满足：

1. 变面积剖面：纵轴 Y = 道号 / 光纤距离（自下而上道号递增），横轴 X = 时间；正振幅区域填充黑色；参数实时调节。
2. 振幅缩放 5 种模式：全局最大值 / 单道最大值 / 全局均方根 / 单道均方根 / 全局平均值；附加 dB 整体增益（-60~60 dB 滑动条）、极性负向翻转、振幅范围（削平）。
3. Wiggle 绘制：每道一条水平基线；波形折线；正振幅多边形填充；支持开启/关闭填充（`填充`、`负向填充` 两个复选项）。
4. 相邻道显示间隔：`地震道`（每 N 道绘制 1 道）或 `像素点`（两道基线像素间距）。
5. 振幅范围：超过设定值后波峰削平。
6. 显示比例：相邻记录间隔——单选 `地震道 / 像素点` + 数值输入（与第 4 点同一组控件，避免重复）。
7. 画布交互：鼠标平移、滚轮缩放、框选截取时间道范围；hover 拾取坐标（道号、距离、时间、振幅）。

## 二、交互设计说明

- 需求第 4、6 条实质是同一参数（相邻道显示间隔），因此界面合并为一组控件：
  - `邻道间隔` 下拉框：`地震道` / `像素点`
  - `间隔值` 输入框：
    - `地震道` 下表示“每 N 道绘制 1 道”（N ≥ 1）；
    - `像素点` 下表示“相邻基线像素间距 P”。
  - 像素点模式换算：`步进 = round(P × 通道数/像素列高)`。通道数/像素由当前 y 轴可视范围与 ViewBox 高度求得，因此在 `像素点` 模式下缩放/平移 y 轴会按 40 ms 节流重建剖面，保证相邻基线约等于设定的像素间距。

## 四、实现（scripts/render/space_time_view.py）

### 4.1 数据结构

```python
class SpaceTimeView(QWidget):
    cursor_info = pyqtSignal(str)          # hover 坐标
    WIGGLE_SCALE_MODES = [...]              # 5 种缩放模式
    MAX_WIGGLE_TRACES = 150                 # 单屏幕最多绘制条数（防卡顿）

    self._plot_mode = "image"               # "image" | "wiggle"
    self._wiggle_items: list[PlotDataItem]      # 波形折线
    self._wiggle_fills: list[PlotDataItem]      # 填充多边形
    self._wiggle_baselines: list[PlotDataItem]  # 每道水平基线
    self._wiggle_params: dict = {...}
```

### 4.2 模式切换

- `set_plot_mode(mode)`：把 `_plot_mode` 置为 `image` 或 `wiggle`，然后 `_sync_visible_items()`。
- `_sync_visible_items()`：
  - image 模式：`image_item` 与右侧 `histogram_widget` 显示，Wiggle 三类 item 隐藏；
  - wiggle 模式：图像与色标隐藏，`_refresh_wiggle()` 全量重建剖面。
- `set_data()` 尾部统一调用 `_sync_visible_items()`，保证加载数据后两种模式都正确刷新。

### 4.3 剖面重建 `_refresh_wiggle()`

1. 移除旧 item（折线/填充/基线三类列表清空）。
2. 由 `_wiggle_spacing_step()` 计算步进，生成待绘道号数组 `[y_start, y_end+1]`，步长：
   - `地震道`：`max(1, round(N))`；
   - `像素点`：`max(1, round(P × (y_span) / viewBox_height_px))`。
3. 若道数超过 `MAX_WIGGLE_TRACES`，等比放大步进，控制在 150 条内。
4. 一次计算公共量：`slice_amp`（全局 |振幅| 最大）、`slice_rms`、`slice_abs_mean`。
5. 对每条道：
   - 取 `matrix[:, ch]`（`matrix = frame_data[:, y_start-1:y_end]`，view 不拷贝）；
   - 按模式计算缩放 `scale`：
     - 全局最大值 / 全局 RMS / 全局平均值 → 用 4 步公共量；
     - 单道最大值 / 单道 RMS → 用该道自身量；
   - `scaled = trace × scale × 10^(gain/20)`；勾选 `负向翻转` 时取负；`clip>0` 时 `np.clip(scaled, -clip, clip)` 削幅；
   - `baseline = ch`（在通道坐标系中，y 轴刻度可继续用 `DistanceAxisItem` 显示物理距离）；
   - 折线 item：`(t, baseline + scaled)`，黑色 1.0 px 笔，peak 降采样 + clipToView；
   - 基线 item：两端点 `(0, ch)→(duration, ch)`，灰色 0.8 px 笔，clipToView（2 个点即可，开销极小）；
   - 填充 item（仅 `填充` 勾选时）：
     - `负向填充` 未勾选 → `fill_y = baseline + max(scaled, 0)`（只填充正振幅）；
     - `负向填充` 勾选 → `fill_y = baseline + scaled`（正负都填充）；
     - `brush=black`、`fillLevel=baseline`，`setZValue(-1)` 垫在折线之下。
6. 先 `addItem` 再加入（设置 clipToView/降采样放在 addItem 之后），避免 pyqtgraph 0.13.7 瞬时父链未建立时 `PlotWidget.autoRangeEnabled` 的 AttributeError 噪音。

性能要点：

- 折线/填充使用 `setDownsampling(auto=True, method="peak")` + `setClipToView(True)`，显示层自动按可见像素数降采样并裁剪，平移缩放时无需重建（`像素点` 步进除外）。
- 全局量只算一次；单道量只对绘制道计算。
- 道数上限 150，超出自动加步进，避免创建上千个 item 卡顿。

### 4.4 交互与 hover

- 鼠标平移 / 滚轮缩放 / 框选放大沿用 `ViewBox.RectMode`（已有），框选即截取时间道范围。
- hover：`scene().sigMouseMoved` → `vb.mapSceneToView(pos)` 得到 `(t, y)`：
  - `channel = round(y)`，夹到 `[1, points]`；
  - `frame = clamp(int(t × sample_rate))`；
  - `amplitude = frame_data[frame, channel-1]`；
  - `distance = 第一道位置 + (channel-1) × 道间距`；
  - 通过 `cursor_info` 信号发到主窗口状态栏：`道号 X | 距离 Y m | 时间 T s | 振幅 A rad`。

### 4.5 其他联动

- 参数编辑采用即时更新：`textEdited` / `currentTextChanged` / `toggled` / `gain_slider.valueChanged` 均触发 `_apply_wiggle_settings()`（不重新读文件）。
- `Apply`、`Reset` 后仍会经 `_render_current_data -> _apply_wiggle_settings()` 保持当前模式与参数。
- 参数持久化键：`tab1/plot_mode`、`tab1/wiggle_scale`、`tab1/wiggle_gain`、`tab1/wiggle_flip`、`tab1/wiggle_clip`、`tab1/wiggle_fill`、`tab1/wiggle_fill_negative`、`tab1/wiggle_spacing_mode`、`tab1/wiggle_spacing_value`。
- `Reset` 恢复默认：时空颜色图、全局最大值、增益 0、不翻转、限幅 0、填充开、负向填充关、地震道、间隔 1。

## 五、数据与坐标系

- Wiggle 剖面直接使用 Tab1 当前 `current_data (frames × points)`，只取 `[Point Start, Point End]` 点段，**不重新读取/滤波文件**。
- 视图坐标保持 1-based 道号；因此水平滚动、垂直滚动、`Back View`、`Zoom Out 2x`、导出窗口逻辑与 time-space 图完全一致，无需分支。
- y 轴刻度沿用 `DistanceAxisItem`：`通道号` 或 `距离(m/km)`，道号自下而上递增。

## 七、后续建议

- 若需绘制超多道（>150），可改用单个自定义 `GraphicsObject` 统一绘制所有道，进一步降低 item 数与构建耗时。
- 当前 `像素点` 步进按近似整数值取整，极端缩放时相邻基线像素间距存在 ±1 px 误差；如需严格等于设定值，需按非均匀间隔重采样道号。
- hover 目前只显示最近采样点幅值，未做时间/振幅插值；如需平滑拾取可增加线性插值。
