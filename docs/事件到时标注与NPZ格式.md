# Tab1 事件到时标注与 eDAS NPZ 格式

更新日期：2026-10-16。

## 1. 标注操作

在 Tab1 将图类型设为 **多道波形(Wiggle)**。下方多道时域图的横轴是时间、纵轴是通道号。

- **Ctrl + 鼠标左键**：在鼠标所指通道标注到时，显示一条局限在该通道附近的红色竖线。每个通道保存一个到时，重复标注会替换原值。
- **按住 Ctrl 和鼠标左键拖过多个通道**：沿鼠标路径连续标注。鼠标事件稀疏、一次跳过多个通道时，对中间通道作线性插值，避免漏道。
- **鼠标悬停到某通道，Ctrl + ← / →**：将该通道已有到时向前/向后移动一个采样点，即 `1 / 当前采样率` 秒。到时被限制在首、末有效样本之间。未标注通道不自动创建标记。
- **Esc**：删除最近创建或修改的一个通道当前标记；长按通过键盘连发持续删除，直至清空。输入框、弹出菜单和对话框保留自己的 Esc 行为。
- **清除到时**：清除当前文件组的全部到时。该操作不会修改数据样本。

未按 Ctrl 的绘图交互保持原有行为。Ctrl+左键在 Wiggle 模式优先用于标注，颜色图模式仍使用原有缩放操作。Ctrl+左右键在悬停通道时优先微调到时，不触发水平翻页。

每个标记在内存中保存为 `通道号 -> 相对当前文件/拼接数据首样本的秒数`。改变增益、滤波、点段、缩放范围或切换颜色图不会清除标记；颜色图下标记隐藏，切回 Wiggle 后恢复。当前会话中不同文件组的标记分开保留。需要跨软件重启保存到时，请导出 NPZ。

## 2. 导出操作

在 Tab1 选择导出目录、格式和抽取步长，然后点击 **导出视图**。导出范围由点击导出时的当前视图确定；任务在后台执行，之后改变视图或切换文件不会改变这次任务的范围、源文件和到时快照。

| 参数 | 默认值 | 行为 |
| --- | --- | --- |
| 导出格式 | BIN | BIN、TXT、NPZ 三选一；原 Save as txt 勾选框由格式选择替代，旧设置可恢复。 |
| Save Filtered Data | 未勾选 | 仅作用于 BIN/TXT：勾选导出当前处理后的数据，未勾选读取原始文件。NPZ 始终保存未滤波原始整数，选择 NPZ 时该选项禁用。 |
| 时间步长 | 1 | 正整数；2 表示保留第 0、2、4…个样本，导出采样率变为当前采样率/2。 |
| 空间步长 | 1 | 正整数；2 表示在当前裁剪范围内每隔一列保留一列。NPZ 保留实际通道号，不重新从 0 编号。 |

两种降采样均为**按步长直接抽取**，不作平均或抗混叠滤波，以保证 NPZ 中 int32 原始值逐项不变。需要频谱分析时，应结合信号带宽选择时间步长；BIN/TXT 勾选 Save Filtered Data 时可先在软件内滤波，再抽取处理后的结果。

多文件拼接的未滤波导出按各源文件原始 int32 数据读取，时间抽取网格跨文件边界连续，不在每个文件重新起算。导出路径不得覆盖本次读取的源文件。

- BIN：原始整数或处理后结果换算的 int32；文件名记录实际导出采样率（允许小数）和保留通道数量。
- TXT：`frames × channels` 浮点弧度矩阵。
- NPZ：未滤波 `int32` 数据 + 头信息 + 范围内保留下来的通道到时。

BIN/TXT 不携带原始通道起点、通道间隔及到时头信息；需要这些信息时使用 NPZ。

## 3. NPZ 文件结构（版本 1）

NPZ 为标准 NumPy 压缩归档，包含以下两个数组，读取不需要 pickle：

- `data`：二维、非空、原生 `int32`，形状为 `(frame_count, channel_count)`。
- `header`：Unicode 字符串标量，内容为 UTF-8 可表示的 JSON 对象。

头信息字段：

| 字段 | 类型/示例 | 定义 |
| --- | --- | --- |
| `data_type` | `"eDAS"` | 必须精确匹配；其他类型或缺失时拒绝读取。 |
| `format_version` | `1` | eDAS NPZ 协议版本。 |
| `dtype` | `"int32"` | 数据类型声明，必须与 data 一致。 |
| `raw_unfiltered` | `true` | 原始未滤波数据标记。 |
| `frame_count` | 整数 | 实际保存的帧数。 |
| `channel_count` | 整数 | 实际保存的通道数，表示数量。 |
| `sample_rate_hz` | 正数 | 导出后的采样率，等于本次输入采样率/时间步长。 |
| `source_sample_rate_hz` | 正数 | 本次导出所用输入文件/拼接数据的采样率。 |
| `start_time` | ISO 8601 字符串或 null | 本文件第一个保留样本的采集时间；时间裁剪后同步偏移。源时间未知则为 null。 |
| `acquisition_start_time` | ISO 8601 字符串或 null | 最初源数据开始采集的时间，重复裁剪导出时保留。 |
| `channel_start` | 非负整数，默认 0 | 本文件第一列对应的原始通道号，裁剪后可能不为 0。 |
| `channel_step` | 正整数，默认 1 | 相邻保存列之间的原始通道号间隔，空间抽取后累计增大。 |
| `channel_numbers` | 整数列表 | 每一列的原始通道号，满足 `channel_start + i*channel_step`。 |
| `arrivals` | 对象列表 | 已标注且保留在本次导出中的通道到时，允许为空。 |
| `arrival_time_reference` | `"seconds_from_first_sample"` | 到时以本文件首个保存样本为 0 秒。 |
| `time_downsample` / `space_downsample` | 正整数 | 本次导出的时间/空间抽取步长。 |
| `downsample_method` | `"stride_without_filtering"` | 按步长抽样，不滤波、不平均。 |
| `source_files` | 字符串列表 | 本次导出直接使用的源文件列表。 |

`arrivals` 按当前剩余标记的最近修改顺序保存，读取后可继续撤销。每一项为：

```json
{"channel": 24, "time_s": 0.125}
```

`channel` 为原始通道号，每个通道最多一项；`time_s` 为相对导出首样本的秒数。到时不强制四舍五入到新的采样网格，以保留鼠标标注的时间精度。只保存本次空间抽取实际保留的通道，并剔除首样本之前、末个保留样本之后的到时。

例如当前视图时间为 1～3 秒，起始通道 20、终点 30，时间步长 2、空间步长 2：输出通道为 20/22/24/26/28/30，`channel_start=20`、`channel_step=2`；原到时“通道 24、1.125 秒”在输出中保存为“通道 24、0.125 秒”。

## 4. 读取与重新导出

文件列表支持 `.bin`、`.bz`、`.bzs`、`.npz`。NPZ 读取依据头信息，不要求文件名具有 BIN 的命名格式。程序严格检查 eDAS 类型、版本、原始整数类型、矩阵大小、采样率、通道映射与到时范围；普通 NumPy NPZ 文件不能当作 eDAS 数据读取。

导入 NPZ 后恢复采样率、文件起始时间、原始通道编号和红色到时标记。若文件保留的是通道 20/22/24，则图轴、输入范围、波形、通道分析和标记继续使用 20/22/24；输入已经被空间抽取移除的通道号会报错。矩阵内部列索引仍为 0/1/2，通过头信息映射至原始通道号。

物理距离仍按“首道位置 + 原始通道号 × 道间距”显示；道间距表示原始相邻通道的物理间距，f-k 计算会乘上保存的通道步长。Tab5 的显示轴也保持原始通道间隔。

同组多文件拼接要求通道数量、通道起点、通道步长和采样率一致；按文件时间/名称排序后沿时间轴拼接。同一通道在多个输入 NPZ 中都有到时时，采用该组按顺序遇到的第一个到时，之后可在图上重新标注。

## 5. Python 读取示例

```python
import json
import numpy as np

with np.load("example.npz", allow_pickle=False) as archive:
    header = json.loads(archive["header"].item())
    assert header["data_type"] == "eDAS"
    data = archive["data"]  # int32, frames × channels
    channels = header["channel_numbers"]
    arrivals = header["arrivals"]
```

完整校验可直接使用 `scripts.io.npz_codec.read_edas_npz`。
